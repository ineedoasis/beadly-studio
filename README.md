# Beadly Studio

사진을 120색 펄러비즈 코드표에 맞춘 도안으로 변환하는 정적 웹앱입니다.

## 기능

- 사진 업로드 및 드래그 앤 드롭(JPG, PNG, WEBP, HEIC/HEIF)
- 가로·세로 8~160 비즈 설정
- 쉽게 / 어렵게 변환
- 120색 코드 기반 색상 매칭
- 비즈 도안과 사용 색상 미리보기
- 코드가 표시된 PNG 및 CSV 다운로드
- 서버 업로드 없이 브라우저 안에서 이미지 처리

HEIC/HEIF는 브라우저가 직접 열지 못할 때에만 `heic2any`를 지연 로드해 기기 안에서 JPEG로 변환합니다.

## 배포

추가 빌드 과정 없이 저장소 루트의 `index.html`을 GitHub Pages로 서비스합니다.

> GitHub Pages 사이트는 공개 웹주소입니다. 민감한 사진은 저장소에 올리지 마세요. 사용자가 업로드한 사진은 이 앱에서 브라우저 밖으로 전송되지 않습니다.
